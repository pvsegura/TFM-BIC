## Before connecting any provider that receives personal data

1. Verify from the provider's official documentation: data location, subprocessors, retention, deletion/suppression
   API, security certifications (as facts, not as a compliance claim).
2. Legal/contractual review: DPA, roles, transfer mechanism if data leaves the EU/EEA.
3. Update [EXTERNAL-DATA-FLOWS.md](EXTERNAL-DATA-FLOWS.md), this table, the
   [processing register](PROCESSING-REGISTER.md), the [deletion matrix](DATA-DELETION-MATRIX.md) and the privacy
   notice (`apps/web/src/legal/privacy-notice.ts`, new version id).
