## How the sources were used

- Engineering capabilities were built only where the requirement is clear and technical (export in a structured,
  machine-readable format; deletion; consent withdrawal as easy as giving; minimisation; security of processing).
- Anything requiring interpretation — lawful bases, retention periods, whether a DPIA is required, controller /
  processor roles, transfer mechanisms, whether acknowledgement of the notice must be recorded — is **PENDING**.
- Random blogs and secondary sites were not used as authority.
