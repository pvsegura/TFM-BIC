# M16 — Security Sources

Authoritative sources used for M16 decisions. Where framework behaviour mattered, the documentation
**shipped with the installed version** in `node_modules` was read rather than the latest online
docs.

| Title                                             | URL / location                                                                                        | Used for                                                                                                                                     | Checked    |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| OWASP Top 10:2025                                 | https://top10.owasp.org/2025                                                                          | Category vocabulary for the audit (A01 Broken Access Control … A10 Mishandling of Exceptional Conditions)                                    | 2026-09-26 |
| OWASP ASVS (releases; 5.0.0 is the latest stable) | https://github.com/OWASP/ASVS/releases                                                                | Verification vocabulary; no compliance claim is made                                                                                         | 2026-09-26 |

| OWASP Authentication Cheat Sheet                  | https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html                        | Per-account (not only per-IP) throttling, lockout-DoS caveat, generic messages (S-02)                                                        | 2026-09-26 |
