# M16 — Security Risk Register

Status: M16, 2026-09-26. Security-specific risks of the current implementation. Project-level
risks stay in [docs/risk-register.md](../risk-register.md). Levels are descriptive
(CRITICAL/HIGH/MEDIUM/LOW) and reasoned in the [audit](M16-SECURITY-AUDIT.md); no numeric scores
are used. "Risk" is the level **before** M16's remediation; the status column says what is left.

| ID    | Area                   | Threat                                                                                                                        | Likelihood                                         | Impact                                | Risk   | Existing control                                  | Remediation                                                                                | Status                    |
| ----- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------- | ------ | ------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------- |

| SR-02 | Authentication         | Distributed password guessing against one account                                                                             | Medium                                             | High (account takeover)               | MEDIUM | Argon2id, per-IP limit                            | Per-account login limit (normalised email)                                                 | Mitigated (M16)           |
| SR-03 | Account deletion       | Stolen session guesses the password from many IPs, then deletes the account                                                   | Low                                                | High (irreversible loss)              | MEDIUM | Password + confirm, per-IP limit                  | Per-user limit                                                                             | Mitigated (M16)           |
| SR-04 | AI generation          | Cost abuse from many IPs; shared-NAT classes starved                                                                          | Medium once a paid provider is on                  | Medium (cost / availability)          | MEDIUM | Per-IP limit, cache, concurrency cap              | Per-user limits                                                                            | Mitigated (M16)           |

## M23 — AI Learning Coach (2026-10-06)

| #   | Risk                                                                                                                     | Treatment                                                                                                                                                                                                                                                                                             | Status                                                     |
| --- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 23  | A learner's prompt talks the model into reading another learner's data                                                   | Structural: no tool declares a user id, and every read binds the session's id. A crafted tool call has nowhere to put another user. Tested (route + orchestrator + tool tests).                                                                                                                       | **Mitigated**                                              |
| 24  | The model reveals an exercise's answer before the learner has answered                                                   | `get_exercise_context` returns `correctAnswer: null` until a stored attempt exists; the key comes from M7's own evaluator run on the learner's answer. Tested.                                                                                                                                        | **Mitigated**                                              |
| 25  | Prompt injection extracts the instructions, the key or the configuration                                                 | The key is never in a prompt, a body or a log; the capability surface is the tool map, so there is nothing to extract. Instruction text declines, but is not relied on.                                                                                                                               | **Mitigated** (wording unverified against the real model)  |
| 26  | A learner exhausts the Gemini quota, or runs up a bill                                                                   | Per-user 20/hour and per-address 30/hour, ≤2 concurrent turns, ≤4 tool rounds, capped message/history/tool output, `thinking_level: "low"`. Verified live: the 429 fires with `Retry-After`.                                                                                                          | **Mitigated**                                              |
| 27  | The coach's traffic exhausts the daily quota the offline media pipeline needs                                            | `GEMINI_AGENT_API_KEY` keeps the coach on its own project/key. **Accepted while unset** — documented in m23-ai-agent.md.                                                                                                                                                                              | **Accepted, documented**                                   |
| 28  | A Gemini outage degrades the whole platform                                                                              | The coach is not in `/ready`; failures map to safe 503/502/504 with a message saying the rest works. Verified live with `AI_COACH_PROVIDER=disabled`.                                                                                                                                                 | **Mitigated**                                              |
| 29  | A learner's free text reaches a third party, and the age/EEA terms apply to learner-initiated traffic for the first time | `store: false`, minimised context, nothing persisted; `AI_COACH_PROVIDER` defaults to `fake` and production must choose `gemini` or `disabled` deliberately. The under-18 clause is **still unresolved**; the product owner was shown it and **authorised proceeding on 2026-10-06**.                 | **Accepted risk — an owner decision, not a legal finding** |
| 30  | The model fabricates learner data (a score, a streak, a completed lesson)                                                | Instructions forbid it and tools return only stored facts with "there is no such metric" notes. Verified in the 2026-10-06 run: asked for a study streak it said the application does not track one, then gave the real counts (scenario 8); a recommendation cited real attempt counts (scenario 3). | **Mitigated — re-check after any instruction change**      |
