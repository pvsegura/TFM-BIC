# content/languages/pl

Polish — the first supported language. `language.json` registers it (`pl`, `polski`, `pl-PL`, `ltr`) and
declares A1 as `available` and A2–C2 as `planned`. Only A1 has lesson/exercise content, and that content
is a small, representative **seed set** (five lessons/explanations, nine exercises) that proves the
architecture — it is **not** a complete A1 course and is not CEFR-certified.

`vocabulary/` holds the M9 seed vocabulary (six categories, ~30 entries — see its own README). `phonetics/`
and `metadata/` are reserved for later milestones and hold only READMEs.
