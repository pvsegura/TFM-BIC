Polish vocabulary (M9, extended since): hand-written categories from A1 (`greetings`, `numbers`, `family`,
`food`, `everyday`, `travel`, `days-and-time`) to C2, two or three per later level — about 270 entries in all. Each file is one category and its entries;
see [content/languages/README.md](../../README.md) and
[docs/architecture/content-architecture.md](../../../../docs/architecture/content-architecture.md)
for the format and validation.

This is a seed set, not a complete course: it demonstrates the vocabulary system, it is not a
claim of CEFR coverage. Grammatical facts (gender, plural) are given only where a general,
well-established rule or an explicitly verified source supports them — see
[ADR-022](../../../../docs/adr/adr-022-vocabulary.md) for what was checked and how. Original
wording throughout; no content was copied from a textbook, course or other protected source.
