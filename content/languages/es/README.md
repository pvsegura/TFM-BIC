# content/languages/es

Spanish for Polish speakers — Verbysia's main course. Every item is explained in Polish
(`instructionLanguage: "pl"`) and follows the PUENTE method
([docs/product/verbysia/METODO-PUENTE.md](../../../docs/product/verbysia/METODO-PUENTE.md)).

- `language.json` — A1 `available`; A2, B1, B2 `planned` (not sold until they exist).
- `levels/a1/content/es-day-*` — the free 7-day challenge "7 dni, żeby zacząć mówić po hiszpańsku".
- `levels/a1/exercises/es-day-*` — three exercises per challenge day.
- `vocabulary/` — challenge vocabulary (greetings, core verbs, café and shop, people and family); it feeds the
  memory trainer.

Curriculum: [docs/product/verbysia/CURRICULO.md](../../../docs/product/verbysia/CURRICULO.md). Polish texts need a
native-speaker review before launch.
